# Office Tower Defense

Support and privacy pages for the iOS game *Office Tower Defense*.

- Support: https://actaris51.github.io/office-td/
- Privacy policy: https://actaris51.github.io/office-td/privacy-policy.html

The game's source lives in a separate, private repository. Nothing but these
pages belongs here: the App Store listing points at them, so a broken build of
this repository is a broken store listing.
